# カード管理アプリ v1（軽量構成・画像なし）

## 起動方法

```
npm install
npm start
```

起動後：
- パソコンから：`http://localhost:3456`
- スマホから：`http://<パソコンのIPアドレス>:3456`（同じWi-Fiに接続していること）

デスクトップの「虫カード管理.bat」をダブルクリックすれば、起動してブラウザも自動で開きます。

★ポートは3456です（3000は他プロジェクトと衝突するため変更しました）。

## v1でできること
- カードの手入力登録（カード名／コスト／体力／色／攻撃／効果／レア度／第何弾）
- 登録カードの一覧・名前検索・弾での絞り込み
- 弾ごとの登録進捗表示（登録数／全枚数／残り枚数）
- 登録カードからデッキ作成・保存
- 大会日・使用デッキ・勝敗・メモの記録

## v1でやらないこと（後で追加）
- 画像の撮影・保存（テーブル設計だけ将来追加できるようにしてある）
- OCR自動読み取り
- 複数枚一括撮影
- CPU対戦
- 複数ユーザー利用（ただしデータ構造はuser_idで分離済み）

## データ
`data/data.sqlite` にすべて保存されます（初回起動時に自動作成）。
