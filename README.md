# 虫神技アプリ（カード管理アプリ）

## 使い方（2026-09-11〜）

**どの端末でも、このURLを開くだけです。Wi-Fiが無くても登録できます（後で自動反映）。**

```
https://mushijingi-app.onrender.com/cards/new
```

パソコンを起動しておく必要はありません。24時間いつでも、どこからでも使えます。

デスクトップの「虫カード管理.bat」はこのURLを開くだけの物に更新済みです。

## 開発者向け：ローカルでの起動方法

```
npm install
npm start
```

- `http://localhost:3456` でローカル確認用に動きます（データはローカルの`data/data.sqlite`）
- 本番（クラウド）は`TURSO_DATABASE_URL` / `TURSO_AUTH_TOKEN` の環境変数でTursoに接続（Renderに設定済み）
- コード管理：https://github.com/voicebooklab/mushijingi-app
- ホスティング：Render（無料プラン）
- データベース：Turso（無料プラン・東京リージョン）

## v1でできること
- カードの手入力登録（虫／術／強化の3種類、それぞれ専用項目）
- 登録カードの一覧・名前検索・弾での絞り込み
- 弾ごと・全弾合計の登録進捗表示
- 登録カードからデッキ作成・保存・過去デッキ登録・デッキ比較
- 大会・各試合の記録
- カードごとの攻略メモ
- 音声入力（🎤ボタン）
- **オフライン対応**：Wi-Fiが無いところでも登録画面が開け、登録内容は端末に保存→再接続時に自動反映

## v1でやらないこと（後で追加）
- 画像の撮影・保存
- OCR自動読み取り
- 複数枚一括撮影
- CPU対戦
- 複数ユーザー利用（ただしデータ構造はuser_idで分離済み）
